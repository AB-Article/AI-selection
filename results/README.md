# results/

Everything here is generated by `run_all.sh` from `data/`. The copies shipped
in the archive are the ones the article reports, so a fresh run can be checked
against them by diffing.

| File | Produced by | Holds |
|---|---|---|
| `results.json` | `analysis_main.py` | every scalar quoted in the main text |
| `stats_meta.json` | `stats_meta.py` | pooled price, tau, Q, I-squared, confidence and prediction intervals |
| `table_cells.csv` | `analysis_main.py` | per-cell fitted parameters |
| `table_rules.csv` | `analysis_main.py` | selection rules scored against the fitted frontier |
| `table_meta.csv` | `stats_meta.py` | per-cell bootstrap intervals |
| `table_aicc.csv` | `stats_meta.py` | per-cell model selection |
| `table_splithalf.csv` | `stats_meta.py` | per-cell split-half refits |
| `table_floor.csv`, `floor_identification.json` | `floor_identification.py` | identification rule applied per cell |
| `table_extended.csv`, `stats_extended.json` | `stats_extended.py` | out-of-domain corpus (group O) |
| `table_llm.csv`, `stats_llm.json` | `stats_llm.py` | language-model corpus (group L) |
| `table_latladders.csv`, `stats_latladders.json` | `latency_ladders.py` | latency ladders |
| `stats_latfinal.json` | `latency_final.py` | prospective test with the price frozen in advance |
| `stats_joint.json` | `joint_llm.py` | joint capacity and latency analysis |
| `table_retired*.csv`, `stats_retired.json` | `analysis_retired.py` | retired-benchmark positive control (group R) |
| `table_censoring.csv`, `stats_retired_final.json` | `retired_stats.py` | censoring analysis |
| `table_bias.csv`, `bias_audit.json` | `bias_audit.py` | Pareto-selection and winner's-curse bias |
| `noise_model.json` | `noise_model.py` | test-set noise sensitivity |
| `decision_logspace.json` | `decision_logspace.py` | decision experiment repeated in log space |
| `minimax_verification.json` | `verify_minimax.py` | numerical Bayes and minimax grid searches |
| `reconciled.json`, `final_estimate.json`, `table_final.csv` | `reconcile.py`, `finalize.py` | cross-checks that quoted scalars agree across stages |
| `robustness.json` | `robustness.py` | winner's curse, calibration, clustered pooling, metric dependence |
| `final_numbers.json` | `make_figure.py` | implied valuations behind the economics figure |
| `logs/` | all stages | stdout of each script |

`robustness.json` carries `_stages_completed` and `_complete`. If `_complete`
is absent or false the run was interrupted and the file holds only the stages
listed; rerun `python3 scripts/robustness.py` to finish it.
